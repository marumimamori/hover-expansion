First public beta release of Hover Expansion.

- Reveal the left and right sidebars by hovering at the window edges.
- Keep a sidebar open while dragging files over its area, including files from another application.
- Select sidebar and page tabs on hover, including tabs in popout windows.
- Choose Direct, Smooth, or Overshoot (experimental) animations.
- Adjust animation duration, expansion and fold delays, tab delay, and edge hover area.
- Default to a 300 ms animation and a 30 ms sidebar expansion delay.
- Move the right expansion icon and adjacent header controls smoothly with the sidebar, including controls added by other plugins.
- Restore individual settings with reset arrows that show their default values.
- Respect reduced motion and restore the original sidebar states when disabling the feature or plugin.

Install with BRAT using `https://github.com/marumimamori/hover-expansion`.

Desktop only. The plugin operates locally, does not read note contents, and includes no telemetry.

Validation: 51 automated checks pass, alongside rendered animation checks and testing in the development vault.
